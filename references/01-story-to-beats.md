# 01 · 故事 → 8 拍

输入：一段 50–500 字的文字。输出：一张能直接照着拍的 8 拍表。这一步决定片子成不成立，别省。

## 第一步：找"可见的那件事"

把故事里所有**心理词**划掉（他想通了 / 他终于自由 / 她明白了 / 世界变好了）。
剩下能拍的只有：**动作、物体、空间、光**。然后把心理词改写成这三类的组合。

| 原文（不可拍） | 改写（可拍） |
|---|---|
| 他终于自由了 | 锁链一节节断裂 → 他走出门 → 天亮了 |
| 这个世界活了过来 | 地面裂开 → 草顶出来 → 一颗颗点亮 |
| 她渐渐被遗忘 | 名字牌一个个掉色 → 街上的人走过不看它 |
| 团队很努力 | 128 个小人排队盖章 → 桌面堆满文件 |

**判据：这句话能不能用三张静帧说清楚？** 不能就继续改。

## 第二步：填 8 拍

构建片与故事片共用一套能量骨架，只是"拍"的内容不同。

| # | 拍 | 时长占比 | 构建片 | 故事片 |
|---|---|---|---|---|
| 1 | Hook | 5% | 一句指令 / 一个空场 / 一颗种子 | 角色 + 它想要的东西（可见） |
| 2 | 起 | 15% | 第一个大动作落地 | 常态被打破（一个动作，不是旁白） |
| 3 | 铺 1 | 15% | 生长类动作，越来越快 | 第一次尝试（失败） |
| 4 | 铺 2 | 15% | 第二、三个动作 | 第二次尝试（失败得更贵） |
| 5 | Burst | 15% | 规模爆炸（一片/一群/整座） | 转折：换个办法 |
| 6 | 暗 | 10% | 能量骤降：天黑 / 静音 / 空镜 | 代价：失去一样东西 |
| 7 | 亮 | 15% | 点亮 / 全景 | 用新的方式完成 |
| 8 | 落点 | 10% | 一句话 + 停在最亮一帧 | 全景 + 一句话 |

**时长预算**：30s / 45s / 60s / 90s 四档。低于 20s 只能做"一个动作"；超过 90s 拆章，
每章 45–70s，章之间用同一套镜头语言。

## 第三步：写一行动词表（最重要的一张纸）

每拍只允许一个动词，且必须是**看得见的变化**：

```
01 hook    落下    一颗种子掉在土上
02 起      顶出    芽冲破土面
03 铺      伏倒    风把草压向一边
04 铺      铺开    绿色从中心向外扩
05 burst   长出    56 棵树从近到远弹出
06 暗      暗下    天空由蓝转深蓝
07 亮      亮起    萤火虫与星星出现
08 落点    静止    一句话，画面停住
```

写不出一行动词的那一拍，就是没想清楚。

## 第四步：能量曲线（画出来，不要口头说）

```
能量
1.0 |                        ▲ burst
0.8 |              ▲ 铺        \
0.6 |      ▲ 起      \         \   ▲ 亮
0.4 |  ▲ hook         \         \ /
0.2 |                   ▼ 暗
    +--------------------------------→ 时间
```

规则：

- **hook 必须在 3 秒内起**（第一个可见变化）。
- **burst 是全片最高点，只有一个。**
- **暗是必要的**：没有那一下俯冲，后面的"亮"不值钱。
- 落点之后**不要再起**（除非有下一章）。

## 第五步：写 `story.md`（交付物模板）

```markdown
# <片名>
一句话：<一句能说清全片的话>
体裁：构建片 / 故事片 / 混合     时长：<n>s     画幅：16:9 / 9:16

## 8 拍
| # | 拍 | 起止 | 动词 | 画面（一句） | 音效 |
|---|---|---|---|---|---|

## 视觉
调色：<3 个颜色 + 出处>   光：<主光方向 / 时间>
参考：<最多 2 张图的位置或链接>

## 落点
最后一句话：<中文> / <英文>
```

## 常见病（写完对照一遍）

- **拍子太多**（>10 拍，90s 也装不下）→ 合并同类动作。
- **动词是"展示/介绍/呈现"** → 这不是动词，是 PPT。
- **没有"暗"** → 全片一条直线，观众提前疲劳。
- **落点又起了一次高潮** → 片子停不下来，观感是"没做完"。
- **故事里出现两个人以上** → 60s 撑不住，砍成一个人 + 一个对象。
