# 02 · 叙事动作 → 镜头语法

这是本 skill 的核心页。**每个镜头都要能填进下面一行。填不进去就是装饰，删掉。**

四列的含义：动作（故事要说什么）· 实现（代码怎么做）· 镜头（观众站哪）· 音效（什么时候落地）。

## 生长类

| 动作 | 实现 | 镜头 | 音效 |
|---|---|---|---|
| **出现 / 落下** | 物体从画外沿抛物线进入，落地时挤压拉伸（`squash` 0.8→1.05→1） | 低机位，前景留白 | 落地 `thud`，进入时 `whoosh` |
| **顶出 / 升起** | `scale.y` 从 0 用弹簧（`L.spring(p, 0.16)`），顶点不动 | 贴地仰拍，物体压住天空 | `riser` 由低到高，落点 `hit` |
| **长出** | 同一几何分批 pop（按到相机距离排序 birth），每株带一次回弹 | 中景横移，让先后关系可读 | 密集 `pop`（每 3–5 株一颗音符） |
| **铺开 / 展开** | 面片 `scale.x` 从一端长到另一端；或实例按路径顺序出现 | 顺铺开方向推镜 | `whoosh`（时长=铺开时长） |
| **聚集** | InstancedMesh 数量 0→N，个体沿路径汇入，末尾轻微散开 | 俯拍，或用跟拍让数量感从画面边缘涌进来 | 由疏到密的 `tick` |
| **膨胀** | 整体 `scale` 从 0.2→1 用 `easeOutBack`，材质由暗到亮 | 缓慢后拉，把新体量装进画 | `subdrop` 或低鼓 |
| **缓慢降落** | 目标物沿慢曲线滑到落点（2–4s，`easeInOut`）+ 1–2% 呼吸；不是抛体 | 让落点留在画面里，镜头别追 | 单音铺底，落点 `chime` |

## 建成类

| 动作 | 实现 | 镜头 | 音效 |
|---|---|---|---|
| **建造** | 房屋逐栋弹出；先出墙框，再出屋顶，最后亮窗 | 航拍或 45° 俯视 | 木鱼/敲击，每栋一下 |
| **堆叠 / 砌** | 体素块按层出现，每层加一点随机旋转 | 侧向长焦，压缩空间 | `stamp` 或短促 `click` |
| **接通 / 连起来** | 细长几何 `scale.z` 从 0 拉满，两端各落一个节点 | 沿连线方向跟拍 | `draw`（笔刷声） |
| **装配** | 若干零件从四周飞入合体，最后一帧轻微回弹 | 固定机位，让装配占满画 | 金属 `click` × 零件数 |

## 变化类

| 动作 | 实现 | 镜头 | 音效 |
|---|---|---|---|
| **点亮** | emissive 逐个拉高 + 光晕 sprite 呼吸（`sin` 幅度 0.1） | 降机位，让光污染画面下半 | 音符逐个上行（`ding` 递进音阶） |
| **变色 / 转季** | 材质颜色按 time 关键帧插值，同一批物体错开 0.2–0.6s | 远景静止，只看颜色变 | 长音铺底，不加节奏 |
| **风化 / 失去** | 去饱和 + 逐个 `scale→0` + 粒子落下 | 缓慢后拉 | 反向 cymbal，末帧静音 |
| **裂开 / 断裂** | 物体切成几块，各自落向一侧并旋转 | 低机位，裂缝对镜头 | `impact` + 碎石 `thud` |

## 角色类

| 动作 | 实现 | 镜头 | 音效 |
|---|---|---|---|
| **走近 / 抵达** | 沿路径前进，身体 bob（`abs(sin)` × 0.02），脚交替 | 跟拍，背景流动 | 脚步声（可省） |
| **跳 / 跃起** | 抛物线 + 起跳前压缩 + 落地回弹 | 侧向，留起落空间 | `boing` + `thud` |
| **注视 / 抬头** | `look` 角度插值 + 眼球方向（有眼睛时） | 反打：角色在前景虚化，焦点在它看的东西 | `tick`（很轻） |
| **转身 / 发现** | `rotation.y` 用 `easeOutBack`，带一次轻微过冲 | 固定中等景别 | `whip` 或 `whoosh` |
| **蹲下 / 按下 / 坐下** | `pose({ crouch: 1 })` / `{ sit: 1 }` / 加 `{ reach: 1 }` 向前下伸；按下时在身前加一次 0.15s 加速再定住 | 低机位侧 3/4，让"手—目标"同框 | 布料/土 `tick`，按下 `thud` |

## 情绪类（靠镜头，不靠特效）

| 动作 | 实现 | 镜头 | 音效 |
|---|---|---|---|
| **压迫** | 不动画面，只让相机极慢推近 5% | 长焦 + 俯拍 | 低频 drone 渐强 |
| **辽阔** | 后拉 + 抬高 + 增大 fov | 落点全景 | 和弦展开 |
| **失控** | 速度突变（0.2s 内完成别的镜头 2s 的运动量） | 手持感：极小幅度随机抖（用播种随机） | 断奏 / 静音一拍 |
| **宁静** | 几乎不动的构图 + 一个缓慢的呼吸级变化 | 固定，让观众读到细节 | 单音，尾巴留长 |

## 复合镜头怎么拆

一个镜头里最多两个动作，且必须**一个主一个辅**：

```
主：森林从近到远长出        （叙事）
辅：相机缓慢抬起            （呼吸）
```

三个以上同时发生 = 观众什么也没看清。要三个，就切成两个镜头。

## 构图约束：目标物必须在场

故事片的每一次"想要"，都要求**角色与目标物同时可读**。这不是动作，是约束：

- 目标（月亮/高塔/门/对面的东西）在**近景时也不能出画**，至少留在画面上缘或角上。
- 一次只能有一个"新信息"进画；目标物进出画必须由一个动作解释（角色抬头/相机抬升）。
- 落点那一镜，目标物必须**与角色同框**——这是"够到了"的唯一证据。

**FOV 的量化口径**（省两轮返工）：设角色与目标在画面上的垂直角差为 θ，则

```
θ  >  fov/2      → 一定切掉一个：先把 fov 抬到 2θ 以上，再把 look 点放到两者角平分线上
θ  >  40°        → 单个镜头装不下，拆镜：先给目标一个空镜（抬头看），再给角色（伸手）
```

实测：角色在 y≈0.2、月亮在 y≈6.4、水平距离 6 时，θ≈46°，fov 34 必切；
改成 fov 42 + look 在角平分线，两秒内就构图成立。

## 反面清单（看到就改）

- 镜头在动、画面没变（相机飘移当叙事）。
- 物体只是"淡入"（`opacity 0→1`）——观感是幻灯片换页，不是世界在长。
- 高潮段落用慢动作补足——慢动作不制造能量，只稀释。
- 全片相机一直缓慢前进（没有静止 → 没有对比 → 没有节奏）。
- 字幕承担了画面没讲清的信息（观众在读，不在看）。
