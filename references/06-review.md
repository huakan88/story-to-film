# 06 · 审片：机器检查 + 冷审片

片子做完不等于能交。两个视角缺一不可：**你自己看**（知道为什么这么做，容易自我说服）和
**一个没参与的 agent 冷看**（只看成片，不给你面子）。

## 第一步：机器检查

```bash
om check .                 # 结构 / 脚本 / 运动 / 文字对比度 / 版面
om still . --at 1,6,11,16  # 关键帧（逐张看，不要只看一张）
node scripts/qa-sheet.mjs out/film.mp4    # 成片 4 秒一格联络表
om qa .                    # 渲染后：单帧闪、死时间、切点、运动曲线
```

`om check` **0 errors 才算过**。有 error 时它同时会关掉版面和对比度检查（会显示 `0 sample(s)`），
所以别把"没有报错"当成"没问题"。

### 新工程一定会遇到的 3 条 warning（不是 bug）

```
warning low-contrast  0.00s  body / #film / #ui  "<字幕占位文案>"  contrast 1.2–3.5:1
```

字幕在 0.00s 还没显示（`opacity: 0`），检查器仍按最终颜色算了对比度。**同一组三条、时刻都是 0.00s
就是它**，看 `0 errors` 即可；如果你的字幕真的压在亮背景上，报的时刻会落在字幕可见的时间窗里，
那才是要改的（加暗底/描边/换位置）。

配套的两条也常见：`blank-frame 0.00s`（首帧是淡入黑场，正常）和
`missing CJK font`（骨架不带中文字体，用系统字体；要固定字体就 `om fonts add "Noto Sans SC" .`）。

## 第一步半：确认成片真的有声音

**新工程默认是静音片**：`OM.music` / `OM.sfx` 只是声明，必须跑一次 `om sound .` 才会生成
`assets/sound.wav` 并把 `<audio id="om-sound">` 注进页面；`om render` 不会替你做这一步。
交付前用 ffprobe 验证**有音轨**：

```bash
om sound .                                    # 生成配乐与音效（会改写 index.html 加一个 audio 标签）
ffprobe -v error -select_streams a -show_entries stream=codec_name -of csv=p=0 out/film.mp4
# 期望输出 aac；空输出 = 你交付了一条无声片
```

## 第二步：冷审片（最重要）

派一个**没有参与制作**的 agent，只给它成片 + 一句话背景，让它按下面的维度出结论。
要求：每条结论带**秒数**，最后给一份**按优先级排序、≤8 条**的修改清单。

```
你是一个冷静的剪辑审片人，之前没参与制作。请审这支 <时长> 秒的短片：
1) 0–3s 的 hook：观众知道要看什么吗？
2) 每个场景的"变化"看得清吗？哪个动作看不出在发生？
3) 节奏：有没有哪段太拖（>2s 没变化）或太赶（1s 内信息过载）？
4) 主体：字幕/HUD 有没有挡住关键动作？文字在成片分辨率下读得出来吗？
5) 收尾：落点成立吗？最后一帧是什么？
6) 硬伤：黑帧、单帧闪、穿模、过曝、元素提前入画。
输出：分维度结论（带秒数）+ 按优先级排序的修改清单（≤8 条，每条给秒数 + 怎么改）。
```

经验：**冷审片的第一版意见里，大约 2/3 是真问题**，剩下的看你自己的判断。
本仓库的骨架就是被冷审片打回后改了两轮才定稿的（造河看不出过程、字幕压主体、白闪过长）。

## 12 条人工验收清单（逐条打勾）

- [ ] **静音看一遍**能看懂故事（画面自己会说）
- [ ] hook 在 3 秒内动起来
- [ ] 每个镜头都能填进 `02-shot-grammar` 的一行
- [ ] 有一个明确的 burst，且只有一个
- [ ] 有一段能量骤降（暗/静/空）
- [ ] 落点之后不再起高潮
- [ ] 字幕不与主体重叠；成片里读得出来（≥4.5:1 对比）
- [ ] 相机没有全程同向缓推（至少两种运动方向）
- [ ] 没有 1 秒以上的死时间（除了刻意的静止）
- [ ] 切点之后 0.5 秒内没有元素提前入画
- [ ] 无黑帧、无单帧闪、无穿模、无过曝
- [ ] 最后一帧是"愿意被截图当海报"的一帧
- [ ] **`ffprobe` 确认成片有音轨**（`om sound` 跑过；不是静音片）

## 常见失败模式与修法

| 症状 | 根因 | 修法 |
|---|---|---|
| 观众说"不知道在看什么" | 前 3 秒没有可见变化 / 主体太小 | 把 hook 提前，主体放大 1.5–2× |
| "挺好看但没记住" | 全片同一种动作（都在"生长"） | 插入一次变化类型不同的动作（塌/裂/亮） |
| "有点拖" | 某段只有相机在动 | 加一个可见事件，或压缩时长 |
| "太赶" | 1 秒内三个以上信息 | 拆成两个镜头 |
| "结尾弱" | 落点能量没降，或停在运动中途 | 让画面停住 0.8–1.5 秒再切黑 |
| "字幕看不清" | 压在亮背景上、字号小于 30px@1080p | 加深色底/描边，或换位置 |
| "像 PPT" | 用的是淡入而不是"长出来" | 换 `scale`/生长类动作 |
| "假" | 无阴影、无接触暗部 | 开一盏阴影光，物体底部加接触阴影 |

## 交付前最后三件事

1. `out/` 里只留最终版本（删掉中间版本）。
2. 写一页说明：怎么改（变量在哪）、与最初设想差在哪（诚实清单）。
3. 把成片和联络表一起发出去——**别人先看的是封面帧**。
