# 等不到的月亮

一句话：一个小人想够到月亮，垒塔够不到、塔还塌了，最后种下一颗种子——树替它长到了月亮边上。
体裁：故事片（角色 / 想要的东西 / 阻碍 / 代价 / 换一种办法）
时长：31s          画幅：16:9（1920×1080）      帧率：30（示例渲 30fps；工程本身 60fps 也能渲）
旁白：无          字幕：一句落点（中英）

## 能量曲线

```
1.0 |                                            ▲ 月落到树梢
0.8 |                    ▲ 踮脚            ▲ 长高
0.6 |        ▲ 垒高                  ▲ 种下
0.4 |  ▲ 伸手                   ✕ 塌（0.15）
0.2 |  ──────────────────────────┘
    +------------------------------------------------→ t
       0   4    6.5   12   15   18   22    27   31
```

- hook 在 0.6s 就动起来（角色抬头 + 伸手）。
- 最高点是落点（月亮落到树梢），不是塔顶——故事片的"用新办法完成"才是峰值，这点与构建片不同（见下方"与 01 的偏离"）。
- 15.0–18.0 是唯一的深谷：塔塌 → 去饱和 → 音乐掉到最低。

## 视觉

调色：夜空 `#0e1626 → #24344d`，月光 `#cfe0ff`，石头 `#6f6a63 / #4e4a45`，树 `#3f6b46`，落点暖光 `#ffd9a0`
光：月光从左后上方（冷白、低强度），塔塌后主光压到 0.35 倍；树长起来后回暖
尺度：角色 ≈ 0.55 单位高；塔 7 层 ≈ 2.7 单位；树长到 ≈ 5.2 单位；月亮初始离地 ≈ 7.0 单位
参考：无（原创）

## 落点文案

中文：它没长高，是树替它够到了月亮。
英文：IT NEVER GREW. THE TREE DID.

## 我做不出来的（先写在这里，别塞进片子）

- 石块的"真实抛体 + 碰撞"：只用"回落 + 自转 + 落地压扁"近似，石块彼此不碰撞
- 角色的手：box 角色没有手臂，"伸手"靠身体上仰 + 起跳 + 压扁代替
- 去饱和：用一层灰蓝色 `mix-blend-mode:color` 叠加 + 主光压暗近似，不是真调色

## 与 `references/01` 的一处偏离（有意的）

01 要求"burst 是全片最高点，落点之后不再起"。本片是故事片，**把最高点放在落点**（月亮落到树梢），
把"踮脚"当作第二次尝试；塔塌是唯一的深谷。若照 01 字面把 burst 放在塔顶，片子的情绪就提前用完了。
